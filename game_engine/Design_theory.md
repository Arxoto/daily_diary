# 游戏性理论

## 双循环设计

内循环负责短期内的高频反馈，如每几秒一次有效操作反馈、十几秒一次小奖励、几分钟一次变奏，或是一段时间内压力累积到释放的过程，一个完整的内循环保持在 15-20 分钟为佳

外循环应营造段落感，降低持续刺激的麻木感，提供标志性的记忆点，为内循环的快感提供意义和成就，并给予下一个内循环的驱动力

例如
- 内循环是一场战斗，外循环是角色成长、养成经营建造
- 亦或是是箱庭关卡，基于起承转合设计：机制的引入、行为的熟练、机制的变体、综合的挑战
- 若基础操作较多复杂，可以使用多目标设计，让目标间相互转化

注意内循环与内循环间应提供不一样的节奏和体验，来让大脑放松切换，如战斗是危机感紧张感以及高频爽感、那么建造则应该是安全的自由的轻负担的确定性的

- 大脑思考，极大的成就感满足感，但是脑力活动是很疲惫的，无法持续进行，适合作为大阶段的分割或者可选体验项目
- 简单的思维负担，持续的反馈奖励，低成本获取高回报的上瘾，适合作为主要游玩体验，但是持续刺激会导致阈值提高
- 营造体验反差来缓和持续刺激的麻木，维持刺激的敏感度，提升整体体验时长上限

## 游戏设计底层框架

from https://www.zhihu.com/question/33501667/answer/1931045580051812680

MDA 框架
- M: Mechanics (机制)
  - 底层规则，算法公式数据
- D: Dynamics (动态)
  - 机制作用下产生的玩法和策略
- A: Aesthetics (美学/体验)
  - 最终产生的核心情感体验，如
    - 挑战 (Challenge): 魂类游戏带来的征服感。
    - 探索 (Discovery): 在开放世界里发现未知区域的惊喜。
    - 叙事 (Narrative): 沉浸在动人故事中的感动。
    - 表达 (Expression): 在沙盒游戏里自由创造的成就感。

一般玩家的体验路径是 A -> D -> M ，而设计师的设计路径是 M -> D -> A ，需要“体验先行，逆向设计”

### 游戏乐趣

#### 游戏乐趣的四个关键

from https://www.bilibili.com/video/BV1xy4y197WD

from https://youtu.be/EEmNRRRqgNc

玩家玩游戏时，会交替或同时不间断地感受到四种不同的乐趣

- 困难乐趣（挫折挑战，成就满足，回味回报）
- 简单乐趣（未知探索、角色扮演、视听享受，自发探索游戏世界）
- 社交乐趣（帮助认同、统治控制、群体归属，游戏之外、异步联机、虚拟对象）
- 严肃乐趣（沉思、意义、深刻、启发）

#### 巴图玩家模型(Bartle's Taxonomy)

from https://zhuanlan.zhihu.com/p/120796586

P.S. 参考即可 有些不是很认可

- 杀手型玩家（其他玩家如竞技游戏、游戏其他机制如《咚奇刚：蕉力全开》）
- 成就型玩家
- 探索型玩家
- 社交型玩家

```
                    Acting 行动
                        |
    Killer 杀手         |       Achiever 成就
                        |
                        |
Player 人 --------------+------------- World 世界
                        |
                        |
    Socialiser 社交     |       Explorer 探索
                        |
                    Interacting 交互
```

玩家之间的相关性
1. 成就型玩家会直接被杀手型玩家影响，两者的数量形成一种动态平衡的关系。这两种玩家就像捕食者和猎物一般。如果杀手型玩家的而数量非常多，会严重干扰成就型玩家的游戏体验，因为成就型玩家的目标被直接的打断了。诚然一部分的杀手型玩家的存在会提高成就型玩家完成目标后的成就感，但是总体上来看成就型玩家的数量和杀手行玩家是负相关的。同理，因为成就型玩家很容易成为杀手型玩家的猎物，当成就型玩家增多时，杀手型玩家的数量也会增多。
2. 探索型玩家的数量会直接影响成就型玩家和杀手型玩家之间的动态平衡。因为探索型玩家并不在乎被杀手型玩家伤害，所以探索型玩家的数量并不会被杀手型玩家影响多少。此外，由于探索型玩家不会因为被杀而生气，并且探索型玩家常有一些意料之外的方式反杀杀手型玩家，让杀手型玩家非常挫败，所以杀手型玩家较为痛恨探索型玩家，但并不会影响彼此的数量。
3. 探索型玩家的数量和成就型玩家的数量呈正相关。探索性玩家在游戏社区内提供各种各样的信息，会吸引更多的成就型玩家来挑战游戏。
4. 社交者的数量是一个闭环。当社交者的数量增多时会扩大游戏社区的规模，从而吸引更多的社交者。反之，当一个社区渐渐冷淡下来，社交者的数量也会随之减少。
